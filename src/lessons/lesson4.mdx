# Series de tiempo y estadística no paramétrica

## Lección 1. Series de tiempo



### i Introducción

Una serie de tiempo es un conjunto de observaciones registradas en orden cronológico. Por ejemplo, pueden registrarse ventas, temperaturas, precios o número de clientes por día, mes o año.

Una tienda registró sus ventas mensuales durante 2025. Se desea construir una serie de tiempo y representar gráficamente el comportamiento de las ventas durante el año.

```r id="1keo81"
ventas <- c(100, 110, 115, 120, 125, 135,
            140, 138, 145, 155, 160, 170)

# Crear serie mensual
serie <- ts(ventas,
            start = c(2025, 1),
            frequency = 12)

print(serie)

plot(serie,
     main = "Ventas mensuales de la tienda",
     xlab = "Tiempo",
     ylab = "Ventas")
```

El gráfico permite observar cómo cambian las ventas a lo largo del año. En este ejemplo existe un crecimiento general de las ventas.

---

### ii Componentes de una serie de tiempo

Una serie puede contener diferentes componentes: tendencia, estacionalidad, ciclo y variaciones irregulares. Separarlos facilita comprender el comportamiento de los datos.

Se dispone de la serie `AirPassengers`, incluida en R, que contiene el número mensual de pasajeros de una aerolínea entre 1949 y 1960. Se desea separar sus principales componentes.

```r id="2d5fsf"
# Cargar la serie
serie <- AirPassengers

# Descomponer la serie
componentes <- decompose(serie)

# Mostrar los componentes
plot(componentes)
```

El resultado presenta la serie original y separa la **tendencia**, el **componente estacional** y el **componente irregular**.

---

### iii Componente de tendencia

La tendencia representa la dirección general que sigue una serie durante un periodo prolongado. Puede ser creciente, decreciente o aproximadamente estable.

Una empresa observa sus ventas durante 20 periodos y sospecha que están aumentando aproximadamente 5 unidades por periodo. Se desea representar la tendencia mediante una regresión lineal.

```r id="a38yko"


tiempo <- 1:20

ventas <- 100 + 5 * tiempo +
          rnorm(20, 0, 5)

plot(tiempo, ventas,
     main = "Tendencia de las ventas",
     xlab = "Periodo",
     ylab = "Ventas")

# Modelo de tendencia
modelo <- lm(ventas ~ tiempo)

# Agregar línea de tendencia
abline(modelo)
```

La línea obtenida muestra una tendencia creciente. Aunque existen pequeñas variaciones, las ventas aumentan conforme transcurre el tiempo.

---

### iv Componente cíclico

El componente cíclico representa movimientos ascendentes y descendentes que ocurren durante periodos relativamente largos. A diferencia de la estacionalidad, los ciclos reales no necesariamente se repiten en intervalos exactamente iguales.

Se quiere representar de manera simplificada una actividad económica que atraviesa periodos de crecimiento y disminución. Se simulará un comportamiento cíclico durante 60 periodos.

```r id="afimzn"
tiempo <- 1:60

# Crear ciclo
ciclo <- 20 * sin(2 * pi * tiempo / 20)

ventas <- 100 + ciclo

plot(tiempo, ventas,
     type = "l",
     main = "Comportamiento cíclico",
     xlab = "Periodo",
     ylab = "Ventas")
```

Se observan periodos alternados de crecimiento y disminución. La función seno se utiliza aquí únicamente para ilustrar visualmente el concepto de ciclo.

---

### v Componente estacional

La estacionalidad aparece cuando existe un patrón que se repite regularmente, por ejemplo, cada semana, mes, trimestre o año.

Una empresa presenta un comportamiento de ventas similar cada año: las ventas aumentan en ciertos meses y disminuyen en otros. Se desea simular tres años con el mismo patrón mensual.

```r id="40dmr7"
# Patrón de ventas de enero a diciembre
patron <- c(10, 12, 15, 18, 20, 25,
            30, 28, 22, 18, 15, 35)

# Repetir durante tres años
ventas <- rep(patron, 3)

serie <- ts(ventas,
            start = c(2024, 1),
            frequency = 12)

plot(serie,
     main = "Estacionalidad de las ventas",
     xlab = "Año",
     ylab = "Ventas")
```

El patrón de los doce meses vuelve a aparecer cada año, lo que representa un comportamiento estacional.

---

### vi Componente irregular

El componente irregular representa variaciones impredecibles que no corresponden claramente a una tendencia, ciclo o patrón estacional.

Una empresa normalmente vende alrededor de 100 unidades por periodo, pero diferentes acontecimientos imprevistos provocan variaciones. Se desea simular este comportamiento.

```r id="l3xdp2"

tiempo <- 1:50

irregular <- rnorm(
  50,
  mean = 100,
  sd = 15
)

plot(tiempo, irregular,
     type = "o",
     main = "Variaciones irregulares",
     xlab = "Periodo",
     ylab = "Ventas")
```

Los valores fluctúan alrededor de 100 sin presentar un patrón regular evidente.

# Lección 2. Métodos de suavizamiento en los pronósticos



### i Promedios móviles

El promedio móvil utiliza las observaciones más recientes para suavizar las fluctuaciones de una serie.

Para tres periodos:

$$
PM=\frac{Y_t+Y_{t-1}+Y_{t-2}}{3}
$$

Una empresa registró ventas de `100, 120, 110, 130, 140, 150, 145 y 160` unidades. Se desea calcular un promedio móvil de tres periodos.

```r id="q3sp1b"
ventas <- c(
  100, 120, 110, 130,
  140, 150, 145, 160
)

promedio_movil <- stats::filter(
  ventas,
  rep(1/3, 3),
  sides = 1
)

promedio_movil
```

Por ejemplo, para los tres primeros periodos:

$$
PM=\frac{100+120+110}{3}=110
$$

El promedio móvil reduce las fluctuaciones individuales de las ventas.

---

### ii Promedios móviles ponderados

El promedio móvil ponderado asigna diferentes niveles de importancia a las observaciones. Normalmente se proporciona mayor peso a los datos más recientes.

Las ventas de los últimos tres meses fueron `100, 120 y 110` unidades. La empresa asignará pesos de `20 %`, `30 %` y `50 %`, respectivamente, para pronosticar el siguiente periodo.

```r id="3o4sx2"
ventas <- c(100, 120, 110)

pesos <- c(0.20, 0.30, 0.50)

pronostico <- sum(ventas * pesos)

pronostico
```

**Interpretación.**

$$
100(0.20)+120(0.30)+110(0.50)=111
$$

El pronóstico para el siguiente periodo es **111 unidades**.

---

### iii Suavizamiento exponencial

El suavizamiento exponencial asigna mayor importancia a las observaciones recientes utilizando un parámetro $\alpha$.

$$
F_{t+1}=\alpha Y_t+(1-\alpha)F_t
$$

Una empresa registró ventas de `100, 110, 120, 115, 130, 140, 145 y 150` unidades. Se desea pronosticar el siguiente periodo mediante suavizamiento exponencial con $\alpha=0.30$.

```r id="ebhh0i"
ventas <- ts(
  c(100, 110, 120, 115,
    130, 140, 145, 150)
)

modelo <- HoltWinters(
  ventas,
  alpha = 0.30,
  beta = FALSE,
  gamma = FALSE
)

# Pronóstico del siguiente periodo
predict(modelo, n.ahead = 1)
```

R utiliza las observaciones anteriores para calcular un valor suavizado y producir el pronóstico del siguiente periodo.

# Lección 3. Análisis de regresión de pronósticos



### i Modelo causal

Un modelo causal de pronóstico utiliza variables explicativas que teóricamente pueden estar relacionadas con la variable que se desea pronosticar. Una regresión puede cuantificar la asociación, aunque por sí sola no demuestra causalidad.

Una empresa quiere estudiar la relación entre su inversión en publicidad y las ventas. Se dispone de siete observaciones y se desea construir una regresión lineal.

```r id="zt5nv2"
publicidad <- c(
  10, 15, 20, 25, 30, 35, 40
)

ventas <- c(
  100, 115, 125, 140,
  150, 165, 180
)

modelo <- lm(
  ventas ~ publicidad
)

summary(modelo)

plot(publicidad, ventas,
     main = "Publicidad y ventas",
     xlab = "Publicidad",
     ylab = "Ventas")

abline(modelo)
```

Si la pendiente estimada es positiva, las observaciones muestran que mayores cantidades de publicidad están asociadas con mayores ventas.

---

### ii Estimación de pronósticos

Después de estimar una regresión, pueden introducirse nuevos valores de la variable explicativa para obtener pronósticos.

Utilizando el modelo anterior, la empresa planea invertir **45 unidades monetarias en publicidad**. Se desea estimar las ventas correspondientes.

```r id="5uh7tr"
publicidad <- c(
  10, 15, 20, 25, 30, 35, 40
)

ventas <- c(
  100, 115, 125, 140,
  150, 165, 180
)

modelo <- lm(
  ventas ~ publicidad
)

nuevo <- data.frame(
  publicidad = 45
)

predict(
  modelo,
  nuevo,
  interval = "prediction",
  level = 0.95
)
```

`fit` proporciona el pronóstico central, mientras que `lwr` y `upr` representan los límites inferior y superior del intervalo de predicción del 95 %.

# Lección 4. Estadística no paramétrica



### i Introducción

Los métodos no paramétricos permiten analizar datos bajo supuestos diferentes o menos restrictivos que muchos métodos paramétricos.

Se tienen las calificaciones de siete estudiantes. Como primera descripción de los datos se desea calcular la mediana.

```r id="nbzgnn"
calificaciones <- c(
  70, 75, 68, 90, 85, 80, 77
)

median(calificaciones)
```

La mediana representa el valor central de los datos una vez que estos se ordenan.

---

### ii Escala de medición

Las variables pueden clasificarse en escalas **nominal, ordinal, de intervalo y de razón**. Esta clasificación ayuda a determinar qué análisis estadísticos son adecuados.

Una encuesta contiene cuatro variables: estado civil, satisfacción, temperatura y peso. Se desea representar en R ejemplos de las cuatro escalas.

```r id="8i2fhg"
# Nominal
estado_civil <- factor(
  c("Soltero", "Casado",
    "Soltero", "Divorciado")
)

# Ordinal
satisfaccion <- factor(
  c("Bajo", "Medio", "Alto", "Medio"),
  levels = c("Bajo", "Medio", "Alto"),
  ordered = TRUE
)

# Intervalo: temperatura en °C
temperatura <- c(20, 25, 30, 22)

# Razón: peso en kg
peso <- c(60, 70, 80, 65)

estado_civil
satisfaccion
temperatura
peso
```

Estado civil es nominal porque representa categorías sin orden; satisfacción es ordinal porque sus categorías pueden ordenarse; temperatura Celsius es un ejemplo clásico de intervalo; y peso posee una escala de razón.

---

### iii Métodos paramétricos contra no paramétricos

La selección entre una prueba paramétrica y una no paramétrica depende del diseño, la escala de medición y los supuestos correspondientes.

Dos grupos de estudiantes utilizaron métodos diferentes de enseñanza. Se desea mostrar cómo podrían compararse mediante una prueba t y mediante la prueba no paramétrica de Mann-Whitney.

```r id="9d3yfz"
grupo_A <- c(20, 21, 19, 22, 23)
grupo_B <- c(25, 27, 24, 26, 28)

# Método paramétrico
t.test(grupo_A, grupo_B)

# Método no paramétrico
wilcox.test(
  grupo_A,
  grupo_B,
  paired = FALSE,
  exact = FALSE
)
```

Las dos pruebas estudian diferencias entre grupos desde marcos estadísticos distintos. La elección apropiada depende de las características y supuestos del problema.

---

# Lección 5. Pruebas no paramétricas



### iv Prueba de corridas para aleatoriedad

La prueba de corridas permite estudiar si el orden de una secuencia presenta evidencia contra la aleatoriedad.

Una empresa registró diez observaciones consecutivas de producción. Se desea contar las corridas situadas por encima y por debajo de la mediana como paso para estudiar la aleatoriedad de la secuencia.

```r id="cm2l3k"
datos <- c(
  10, 12, 8, 15, 14,
  9, 7, 16, 18, 11
)

mediana <- median(datos)

# 1 = arriba de la mediana
# 0 = abajo de la mediana
signos <- ifelse(
  datos > mediana, 1, 0
)

# Número de corridas
corridas <- 1 +
  sum(signos[-1] !=
      signos[-length(signos)])

signos
corridas
```

Una corrida corresponde a una secuencia consecutiva de observaciones de la misma categoría. Para realizar una prueba formal completa debe compararse el número de corridas con su distribución bajo aleatoriedad.

---

### v Una muestra: prueba de signos

La prueba de signos permite contrastar una hipótesis sobre la mediana utilizando únicamente la dirección de las diferencias.

Un fabricante afirma que la mediana de duración de su producto es de **50 horas**. Se obtiene una muestra de ocho productos y se desea contrastar la afirmación.

```r id="ecp76e"
datos <- c(
  52, 55, 48, 60,
  53, 51, 47, 58
)

positivos <- sum(datos > 50)

n <- sum(datos != 50)

binom.test(
  positivos,
  n,
  p = 0.5
)
```

Las hipótesis son:

$$
H_0: Mediana=50
$$

$$
H_1: Mediana\neq50
$$

Con $\alpha=0.05$, si `p-value < 0.05` se rechaza $H_0$; si `p-value ≥ 0.05`, no se rechaza $H_0$.

---

### vi Una muestra: prueba de Wilcoxon

La prueba de rangos con signo de Wilcoxon utiliza los rangos de las diferencias respecto a un valor hipotético.

Se desea estudiar si los datos de duración de ocho productos presentan una ubicación central diferente de **50 horas**, utilizando Wilcoxon.

```r id="dphq9w"
datos <- c(
  52, 55, 48, 60,
  53, 51, 47, 58
)

wilcox.test(
  datos,
  mu = 50,
  alternative = "two.sided",
  exact = FALSE
)
```

Si el valor p es menor que el nivel de significancia establecido, existe evidencia estadística contra la hipótesis nula.

---

### vii Dos muestras: prueba de Mann-Whitney

Mann-Whitney permite comparar dos muestras independientes utilizando los rangos de las observaciones.

Dos grupos independientes de estudiantes utilizaron métodos de enseñanza diferentes. Se desea determinar si existe evidencia de diferencias entre sus resultados.

```r id="4m5ovg"
grupo_A <- c(
  65, 70, 68, 72, 66
)

grupo_B <- c(
  75, 80, 78, 82, 77
)

wilcox.test(
  grupo_A,
  grupo_B,
  paired = FALSE,
  exact = FALSE
)
```

Un valor p pequeño proporciona evidencia contra la hipótesis de igualdad de las distribuciones de ambos grupos.

---

### viii Observaciones pareadas: prueba de signos

En las observaciones pareadas, cada medición tiene una pareja natural. Un ejemplo típico son las mediciones realizadas antes y después sobre los mismos individuos.

Se midió el rendimiento de seis estudiantes antes y después de aplicar una estrategia educativa. Se desea determinar, mediante los signos de las diferencias, si existe evidencia de un cambio.

```r id="c4l3hy"
antes <- c(
  70, 65, 80, 75, 68, 72
)

despues <- c(
  75, 67, 85, 74, 72, 78
)

# Calcular diferencias
diferencias <- despues - antes

# Eliminar diferencias iguales a cero
d <- diferencias[diferencias != 0]

# Contar diferencias positivas
positivos <- sum(d > 0)

binom.test(
  positivos,
  length(d),
  p = 0.5
)
```

Se cuentan los estudiantes que mejoraron y los que disminuyeron su resultado. La prueba evalúa si el balance de signos es compatible con la hipótesis nula.

---

### ix Observaciones pareadas: prueba de Wilcoxon

Wilcoxon para muestras pareadas analiza los rangos de las diferencias entre dos mediciones relacionadas.

Utilizando los resultados anteriores de los mismos seis estudiantes, se desea aplicar la prueba de Wilcoxon para determinar si existe evidencia de un cambio entre las mediciones antes y después.

```r id="cok4nm"
antes <- c(
  70, 65, 80, 75, 68, 72
)

despues <- c(
  75, 67, 85, 74, 72, 78
)

wilcox.test(
  antes,
  despues,
  paired = TRUE,
  exact = FALSE
)
```

`paired = TRUE` indica que las muestras están relacionadas. Con $\alpha=0.05$, un valor p inferior a 0.05 proporciona evidencia contra la hipótesis nula.

# Lección 6. Varias muestras independientes: Kruskal-Wallis



### x Prueba de Kruskal-Wallis

Kruskal-Wallis permite comparar **tres o más grupos independientes** utilizando los rangos de las observaciones.

Una institución quiere comparar las calificaciones obtenidas mediante tres métodos de enseñanza: **A, B y C**. Cinco estudiantes diferentes participaron en cada método. Se desea determinar si existe evidencia estadística de diferencias entre los grupos.

```r id="shgrkz"
calificacion <- c(
  # Método A
  70, 72, 68, 75, 71,

  # Método B
  80, 82, 78, 85, 81,

  # Método C
  75, 77, 73, 79, 76
)

metodo <- factor(c(
  rep("A", 5),
  rep("B", 5),
  rep("C", 5)
))

kruskal.test(
  calificacion ~ metodo
)
```

Las hipótesis generales son:

$$
H_0:\text{las distribuciones de los grupos son iguales}
$$

$$
H_1:\text{al menos una distribución difiere}
$$

Si se establece $\alpha=0.05$:

$$
p<0.05 \Rightarrow \text{se rechaza }H_0
$$

$$
p\geq0.05 \Rightarrow \text{no se rechaza }H_0
$$

Si se rechaza $H_0$, Kruskal-Wallis indica que existe evidencia de diferencias entre los grupos, pero **no identifica directamente cuáles grupos son diferentes**. Para ello sería necesario realizar comparaciones posteriores.
