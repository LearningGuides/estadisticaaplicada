## 1. Probabilidad condicional

La probabilidad condicional se representa como:

$$
P(A|B)=\frac{P(A\cap B)}{P(B)}
$$

Por ejemplo, supóngase que de 100 estudiantes, 40 aprobaron Matemáticas, 30 aprobaron Estadística y 20 aprobaron ambas. Se desea conocer la probabilidad de haber aprobado Matemáticas sabiendo que se aprobó Estadística.

```r
# Datos
aprobar_matematicas_y_estadistica <- 20
aprobar_estadistica <- 30

# P(Matemáticas | Estadística)
probabilidad <- aprobar_matematicas_y_estadistica / aprobar_estadistica

probabilidad
# Resultado: 0.6667
```

Esto significa aproximadamente **66.67 %**.

---

## 2. Teorema de Bayes

El teorema de Bayes establece:

$$
P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}
$$

Supóngase que el 40 % de los estudiantes aprueba Matemáticas. De los estudiantes que aprueban Matemáticas, el 50 % también aprueba Estadística. Por otro lado, de los estudiantes que no aprueban Matemáticas, aproximadamente el 20 % aprueba Estadística.

Se desea conocer la probabilidad de que un estudiante haya aprobado Matemáticas, sabiendo que aprobó Estadística.
```r
# Probabilidades
P_matematicas <- 0.40
P_estadistica_matematicas <- 0.50
P_estadistica_no_matematicas <- 0.20
P_no_matematicas <- 1 - P_matematicas

# Probabilidad total de aprobar Estadística
P_estadistica <- (P_estadistica_matematicas * P_matematicas) +
                 (P_estadistica_no_matematicas * P_no_matematicas)

# Teorema de Bayes
P_matematicas_estadistica <- (P_estadistica_matematicas *
                              P_matematicas) / P_estadistica

P_matematicas_estadistica
# Resultado aproximado: 0.625
```
El resultado indica que la probabilidad de que un estudiante haya aprobado Matemáticas, dado que aprobó Estadística, es aproximadamente 66.67 %.

## 3. Distribuciones discretas de probabilidad

Un ejemplo clásico es la **distribución binomial**, que permite calcular probabilidades relacionadas con cierto número de éxitos en varios intentos.

Supóngase que se lanza una moneda 10 veces y se desea calcular la probabilidad de obtener exactamente 6 caras.

```r
# Probabilidad de exactamente 6 caras
dbinom(
  x = 6,
  size = 10,
  prob = 0.5
)

# También se puede visualizar toda la distribución
x <- 0:10
probabilidades <- dbinom(x, size = 10, prob = 0.5)

barplot(
  probabilidades,
  names.arg = x,
  xlab = "Número de caras",
  ylab = "Probabilidad",
  main = "Distribución binomial"
)
```

`dbinom()` calcula la probabilidad de obtener exactamente determinado número de éxitos.

---

## 4. Distribuciones continuas de probabilidad

Una de las distribuciones continuas más utilizadas es la **distribución normal**.

Supóngase que las calificaciones tienen media 70 y desviación estándar 10. Se desea calcular la probabilidad de obtener una calificación menor o igual a 80.

```r
# P(X <= 80)
pnorm(
  q = 80,
  mean = 70,
  sd = 10
)

# Gráfica de la distribución
x <- seq(30, 110, length = 500)
y <- dnorm(x, mean = 70, sd = 10)

plot(
  x, y,
  type = "l",
  main = "Distribución normal",
  xlab = "Calificación",
  ylab = "Densidad"
)
```

`pnorm()` calcula probabilidades acumuladas de una distribución normal.

# Distribuciones muestrales

## 5. Introducción

Una **población** contiene todos los elementos de interés. Una **muestra** es una parte de esa población utilizada para obtener información.

```r
# Crear una población simulada
poblacion <- rnorm(
  n = 10000,
  mean = 100,
  sd = 15
)

# Seleccionar una muestra
muestra <- sample(poblacion, size = 100)

# Comparar medias
mean(poblacion)
mean(muestra)
```

La media muestral normalmente será cercana, aunque no idéntica, a la media poblacional.

---

## 6. Tipos de muestreo

Un procedimiento básico es el **muestreo aleatorio simple**, donde todos los individuos tienen oportunidad de ser seleccionados.

```r
# Población de 100 estudiantes
estudiantes <- 1:100

# Muestra aleatoria de 10 estudiantes
muestra_aleatoria <- sample(
  estudiantes,
  size = 10,
  replace = FALSE
)

muestra_aleatoria
```

También puede realizarse un muestreo sistemático:

```r
# Seleccionar cada décimo elemento
muestra_sistematica <- estudiantes[seq(1, 100, by = 10)]

muestra_sistematica
```

---

## 7. Distribución muestral

Puede simularse la distribución de la media tomando repetidamente muestras de una población.

```r

# Población
poblacion <- rnorm(10000, mean = 50, sd = 10)

# Obtener 1000 medias muestrales
medias <- replicate(
  1000,
  mean(sample(poblacion, size = 30))
)

# Media de las medias
mean(medias)

# Histograma
hist(
  medias,
  main = "Distribución muestral de la media",
  xlab = "Media muestral"
)
```

Las medias obtenidas forman una **distribución muestral**.

# Estimación de errores

## 1. Introducción

El **error de estimación** puede observarse comparando la media poblacional con la media muestral.

```r

poblacion <- rnorm(10000, mean = 500, sd = 50)
muestra <- sample(poblacion, 100)

media_poblacional <- mean(poblacion)
media_muestral <- mean(muestra)

error <- media_muestral - media_poblacional

media_poblacional
media_muestral
error
```

Un error pequeño indica que la estimación muestral se encuentra cerca del parámetro poblacional.

## 2. Estimación estadística

```r
# Muestra de salarios
salarios <- c(
  12000, 13500, 12800, 14200,
  15000, 13800, 14500, 13200
)

# Estimación de la media poblacional
media_estimada <- mean(salarios)

# Estimación de la desviación estándar
desviacion_estimada <- sd(salarios)

media_estimada
desviacion_estimada
```

Los estadísticos obtenidos de la muestra funcionan como estimadores de los parámetros de la población.

## 3. Estimación puntual

Si se desea estimar la media poblacional, puede utilizarse directamente la media de la muestra.

```r
edades <- c(20, 22, 25, 24, 21, 23, 26, 22)

# Estimación puntual
estimacion_media <- mean(edades)

estimacion_media
```

Si el resultado fuera `22.875`, ese número sería la **estimación puntual** de la media poblacional.

---

## 4. Estimación por intervalos de confianza

Un intervalo de confianza del 95 % puede calcularse mediante `t.test()`.

```r
datos <- c(
  15, 17, 14, 18, 16,
  19, 15, 17, 16, 18
)

resultado <- t.test(
  datos,
  conf.level = 0.95
)

# Intervalo de confianza
resultado$conf.int

# Media estimada
resultado$estimate
```

A diferencia de la estimación puntual, aquí se obtiene un **intervalo** dentro del cual se estima el parámetro.

---

## 5. Diferencia entre dos medias poblacionales

Supónganse las calificaciones de dos grupos:

```r
grupo_A <- c(80, 85, 78, 90, 88, 84, 82)
grupo_B <- c(75, 79, 72, 81, 77, 76, 80)

# Medias
mean(grupo_A)
mean(grupo_B)

# Diferencia puntual
mean(grupo_A) - mean(grupo_B)

# Intervalo de confianza
t.test(
  grupo_A,
  grupo_B,
  conf.level = 0.95
)
```

R proporciona tanto la diferencia observada como información para construir el intervalo de confianza correspondiente.

## 6. Diferencia entre dos proporciones binomiales

Supóngase que en el grupo A aprobaron 80 de 100 estudiantes y en el grupo B aprobaron 65 de 100.

```r
exitos <- c(80, 65)
total <- c(100, 100)

# Proporciones observadas
exitos / total

# Diferencia de proporciones
(exitos[1] / total[1]) -
(exitos[2] / total[2])

# Intervalo y prueba de comparación
prop.test(
  x = exitos,
  n = total,
  conf.level = 0.95,
  correct = FALSE
)
```

Las proporciones estimadas son **0.80 y 0.65**, respectivamente.

## 7. Límites de confianza de una cola

Por ejemplo, puede calcularse un intervalo unilateral inferior para una media:

```r
datos <- c(
  45, 48, 50, 47, 52,
  49, 51, 46, 53, 50
)

# Intervalo unilateral inferior
resultado <- t.test(
  datos,
  alternative = "greater",
  conf.level = 0.95
)

resultado$conf.int
```

`alternative = "greater"` produce un límite inferior de confianza. Para obtener uno superior puede utilizarse:

```r
t.test(
  datos,
  alternative = "less",
  conf.level = 0.95
)$conf.int
```

## 8. Selección del tamaño muestral

Para estimar una media cuando se conoce aproximadamente la desviación estándar puede emplearse:

$$
n=\left(\frac{Z_{\alpha/2}\sigma}{E}\right)^2
$$

Supóngase un nivel de confianza del 95 %, desviación estándar de 10 y error máximo permitido de 2.

```r
# Datos
confianza <- 0.95
sigma <- 10
error <- 2

# Valor crítico Z
alpha <- 1 - confianza
z <- qnorm(1 - alpha / 2)

# Tamaño de muestra
n <- (z * sigma / error)^2

# Redondear hacia arriba
n_final <- ceiling(n)

n_final
```

`ceiling()` redondea hacia arriba porque el tamaño de muestra debe ser un número entero y no conviene reducir el tamaño mínimo calculado.
